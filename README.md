# SOUL DUEL / Saigen

2人用の2D弾幕対戦ゲーム。Undertale系の「コマンド選択 → タイミング攻撃 → SOUL回避」という読みやすい戦闘リズムを参考にしつつ、公開可能なオリジナル素材・ルールで対人戦として再設計しています。

## 現在の実装

- ローカル2P（同一PC / 同一スマホ）
- 日本語 / English 切り替え、設定保存
- PCキーボード操作
- スマホ専用マルチタッチ操作
  - 防御側: 仮想スティック
  - 攻撃側: 左右の弾幕干渉ボタン
  - 共通: 決定ボタン
- 縦画面 / 横画面 / ノッチ（safe-area）対応
- 画面回転・リサイズでゲーム状態を維持
- 固定60Hzシミュレーション
- FIGHT / ACT / ITEM / MERCY
- 青弾: 動いているとダメージ
- 橙弾: 止まっているとダメージ
- 4種の決定論的弾幕パターン
- 被弾無敵時間、HPゴースト表示、画面シェイク、パーティクル
- タブ非表示 / アプリ切替時の自動Pause
- Reduced Motion
- WebAudioによるオリジナルSE（外部音源なし）

## 操作

### PC

- P1: WASD / F / Q E
- P2: Arrow keys / Enter / , .
- ESC: Pause

### Smartphone / Tablet

画面下部のタッチUIを使用します。DODGE中は防御側が左スティック、攻撃側が右側の左右ボタンを同時に操作できます。

## 安定性方針

ゲーム判定と描画を分離しています。ゲーム進行は60Hz固定ステップで処理し、CSSアニメーション終了イベントや`setTimeout`を勝敗判定に使いません。タブ復帰時も巨大なデルタ時間をゲームへ流し込まない構造です。

## 権利関係

公式ゲームのスプライト、BGM、SEは同梱していません。UIの設計思想やジャンル上の表現を参考にしつつ、描画・効果音・対戦ルールはこのプロジェクト用に作成しています。
